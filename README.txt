Cara pakai
1. Upload seluruh isi folder ini ke GitHub (index.html, data.js, content.js, logo_uin.png, PDF, PPTX).
2. Deploy ke Vercel atau GitHub Pages. Tombol unduh di pojok kanan atas mengambil file PDF dan PPTX dari folder yang sama.
Kontrol: panah kiri/kanan atau geser di HP, F layar penuh, N menampilkan naskah kecil di bawah (tersembunyi secara default), Esc menutup panel tafsir.
Ubah isi: data.js (ayat, tafsir, naskah) dan content.js (teks slide).
